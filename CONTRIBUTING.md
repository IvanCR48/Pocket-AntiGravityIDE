# Contributing to Pocket Antigravity IDE

Thank you for your interest in contributing to **Pocket Antigravity**! 🎉

## How Can I Contribute?

### Reporting Bugs
- Check the [existing issues](https://github.com/IvanCR48/Pocket-AntiGravityIDE/issues) before opening a new one.
- Use the **Bug Report** template to provide detailed steps to reproduce the issue.

### Suggesting Features
- Open a feature request describing the use case and expected behavior.

### Submitting Pull Requests
1. Fork the repository.
2. Create a feature branch: `git checkout -b feature/my-new-feature`.
3. Test your changes locally on Windows desktop and mobile view.
4. Commit your changes: `git commit -m "Add some feature"`.
5. Push to the branch: `git push origin feature/my-new-feature`.
6. Open a Pull Request on GitHub.

## Local Development
```bash
# Install dependencies
npm install

# Start development server
node src/server.js

# Start tunnel for mobile testing
node scripts/start-tunnel.js
```
